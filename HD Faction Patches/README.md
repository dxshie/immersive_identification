# HD Faction Patches component

This optional FOMOD component bundles the universal `ui_mm_faction_patches.dds`
atlas from **HD Faction Patches 2.4** by **Leekos** under the unique filename
`ui/ii_hd_faction_patches.dds`. Its texture descriptor maps Immersive
Identification's `ii_patch_*` ids to that atlas.

Enable **Custom faction patches** on Immersive Identification's **UI Style / General**
MCM page after installing the component.
